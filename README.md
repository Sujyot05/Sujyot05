## 🚀 Featured Projects

### 🏦 [NovaBanc](https://github.com/sujyot-bhandare) — Full-Stack Banking Management System
A complete digital banking platform built solo, covering both the institution and customer sides of the experience.
- **Two portals:** a branch admin console + a customer self-service portal
- **Security-first:** OTP-based two-step authentication for both staff and customers
- **End-to-end banking flows:** accounts, transactions, loans, cards, fixed deposits, cheque books, KYC, beneficiaries, and scheduled transfers
- **Real-world integrations:** transactional email via Mailjet, in-app notification system
- **Stack:** PHP · MySQL · Session-based auth · RESTful API design (~35+ endpoints)

### 🏥 [Hospital Management System](https://github.com/sujyot-bhandare/Hospital-Management-System) + [Kiosk Machine](https://github.com/sujyot-bhandare/Hospital-Management-System-kiosk-Machine-)
A full-stack hospital platform integrating **RFID** for streamlined patient check-in and digital healthcare records, paired with a dedicated Java-based kiosk interface for on-site use.

### 🪪 [Aadhar Card POS Device](https://github.com/sujyot-bhandare/A-pos-device-to-issue-and-update-aadhar-card-Webcode) — Diploma Final-Year Project
Designed and built a compact **Raspberry Pi 4** POS device for issuing and updating Aadhar cards, replacing bulky legacy hardware with a low-cost, portable solution. Shipped with both a [web backend](https://github.com/sujyot-bhandare/A-pos-device-to-issue-and-update-aadhar-card-Webcode) and a [companion app](https://github.com/sujyot-bhandare/A-pos-device-to-issue-and-update-aadhar-card-App-).

### 🔒 [Secure Upload Drive](https://github.com/sujyot-bhandare/Secure-upload-drive)
A privacy-first, web-based storage tool letting users store and share files on their own server or cloud infrastructure — no third-party lock-in.
